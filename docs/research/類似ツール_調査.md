# 類似ツール 調査

**目的: 「ドキュメントやコードにコメントして Coding Agent に渡す」用途の既存ツールを比較し、reviewbuddy との違いと参考にする点を確認日付きで記録する。**

***

## 前提

- 調査日: 2026-10-23
- 比較の観点: 何を対象にするか / コメントの保存先 / 複数人で使えるか
- reviewbuddy の位置づけ: ローカルで起動し、設定なしで、同じ tailnet 内の複数人がリアルタイムにコメントできる。対象ディレクトリのファイルは書き換えない

***

## 仕様サマリー

| ツール | 概要 | コメントの保存先 | 複数人 | reviewbuddy との差 |
|--------|------|----------------|--------|---------------|
| difit (v5.0.12) | Git diff を GitHub 風の Files changed 画面で表示する CLI。行 / 範囲にコメント → 「Copy Prompt」「Copy All Prompt」。React 18 + Vite + Express + Prism.js | ブラウザの localStorage (コミット単位) | なし (`--host 0.0.0.0` で他の端末から閲覧はできる) | diff 専用・単独利用。プロンプトの `path:L42-L48` 形式は参考になる |
| md-redline | 描画した Markdown 上でテキストを選んでコメントする。MCP 経由で Agent が読み書きできる | Markdown ファイル内に HTML コメントとして埋め込む | なし (README で明言) | 対象ファイルを書き換える点が逆の設計 |
| claude-review | Claude Code のスラッシュコマンドで Markdown のレビューを開始・反映する。Go 製 | `~/.local/share/claude-review` の DB | 記載なし | Claude Code 専用・単独利用 |
| scholia | Markdown のファイル / フォルダをブラウザでプレビューする | — | — | 閲覧のみ |
| commd (旧 ccplan) | Go 製の TUI で Markdown をレビューする。セクション / 行 / 範囲にコメントし、"Please review and address the following comments on:" から始まる指示文を出力する。Claude Code の plan mode にフックで返せる。`commd pr` で GitHub の PR Review にも投稿できる | 出力時に生成 (クリップボード / 標準出力 / ファイル) | ローカルは単独。GitHub 経由なら複数人 | TUI・単独利用。Conventional Comments のラベルは参考になる |
| redpen-review (2026-08 公開) | ブラウザで Markdown / HTML / テキストに赤ペンでフィードバックし、標準出力に出して coding agent に渡す。Claude Code / Codex / opencode 向け。コマンドは `redpen` | 未調査 | 未調査 | 構想が最も近い。複数人対応や保存方式は未調査 |
| Margins (margins-cli) | Git 上の Markdown を Web UI でレビューするサービス。ディスカッションは見出しか選択テキストにひも付き、open / resolved を持つ。CLI と Claude Code プラグインで Agent も参加する | サービス側 | あり (ワークスペースのメンバー、OAuth / API キー) | アカウントが必要なホスト型。ローカル完結・設定なしの reviewbuddy とは逆 |

***

## 重要な気づき

- **複数人がリアルタイムに使えるローカル完結のツールは見当たらない**。単独利用か、アカウントが必要なホスト型に分かれる
- **対象ファイルを書き換えない設計は reviewbuddy の特徴**。md-redline はコメントをファイルに埋め込む
- **プロンプトの形式は difit の `path:L42-L48` と同じ考え方**。reviewbuddy は `path:8-10` の形にする ([プロンプト出力仕様.md](../design/プロンプト出力仕様.md))
- **Agent との直接連携 (MCP、スラッシュコマンド) は他ツールが先行している**。reviewbuddy では v2 の候補とする
