# 名前 調査

**目的: アプリ名を akapen に決めた経緯と、検討した候補・名前の空き状況を確認日付きで記録する。**

***

## 前提

- 調査日: 2026-10-23
- npm は `npm view <name>` が 404 になるかで判定した。mise registry は `mise registry` (2026.10.17 に同梱の一覧、1,067 件) で判定した
- 名前の使われ方: コマンド `akapen .` / 設定・データ `~/.config/akapen/` / mise `github:<owner>/akapen`

***

## 仕様サマリー

### 決定: akapen (2026-10-23)

- **由来**: 赤ペン。添削して直させるイメージが「コメント → Coding Agent が修正」の流れと一致する
- **英語での説明**: "akapen (赤ペン, red pen) — mark up docs and code together, then hand the comments to your coding agent."
- **空き状況**: npm の `akapen` は空き (過去に別の人が公開し、2026-08-22 に unpublish 済み)。mise registry の短縮名も空き。目立つ同名の GitHub プロジェクトは見当たらない (網羅的な検索ではない)

### redpen を見送った理由

- 同じ分野に `redpen` コマンドがすでに 3 つある
  - npm `redpen-review` (2026-08 公開): ブラウザで Markdown / HTML / テキストに赤ペンでフィードバックし、標準出力で coding agent に渡す。akapen とほぼ同じ構想
  - npm `redpen`: AI が書いたコードを監査するレビュー用プロンプト集
  - npm `redpen-cli`: coding agent 向けの完了条件・検証レイヤー
- 技術文書の校正ツール RedPen (Java、603 stars、最終 push 2022-07) が日本の技術ライターに知られている。Homebrew の formula `redpen` もある (非推奨、2027-05-02 に無効化予定)
