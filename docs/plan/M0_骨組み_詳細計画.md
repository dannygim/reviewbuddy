## 目的

後続のフェーズ (M1〜M7) が載る土台を作る。具体的には次の 4 点を固める。

- CLI の入口 (引数解析・エラー表示・終了コード)
- `Bun.serve` + HTML import によるサーバーと SPA の同居
- `bun check` / `bun fmt` / `bun test` による開発ループ
- 単一バイナリのビルドと、そのスモークテスト

## スコープ

- `package.json` / `tsconfig.json` / `.gitignore` の作成、`mise.toml` の Bun を 1.4.4 に固定
- `akapen [dir] [-p|--port] [-H|--host] [-v|--version] [-h|--help]`
- ルートディレクトリの解決 (相対パス → realpath、存在しない / ディレクトリでない場合はエラー)
- `GET /` (SPA)、`GET /api/health`、その他は 404
- 既定ポート 4400 が使用中なら次の空きポート (最大 20 個先まで)。`--port` を明示した場合は移らずにエラー
- React の最小画面 (ヘッダーに "akapen" とルートのパス)。OS のライト / ダーク設定に追従
- `bun run dev` (ホットリロード)、`bun run build` (単一バイナリ)、`bun run verify`

## 非スコープ

- サブコマンド (`export` / `session` / `config`) → M5 / M6
- `--open` / `--new` / `--session` / `--no-watch` → 各機能のフェーズ
- 環境変数 (`AKAPEN_PORT` など) と `config.toml` → M6
- CI とリリース → M7

## タスク分解

### 共通の制約

- Bun は 1.4.4 (`mise.toml` で固定)。依存は `react` / `react-dom` (19.3.1)、開発用に `@types/bun` (1.4.4) / `@types/react` / `@types/react-dom` (19.3.0) のみ。`typescript` は入れない (`bun check` が組み込みのため)
- コマンドはすべてリポジトリのルートで実行する
- UI の文言は英語。コードのコメントも英語
- 各タスクの最後に `bun run verify` を通してから commit する。整形で落ちたら `bun run format` を実行してからやり直す
- `bun fmt` を引数なしで実行しない。Markdown や TOML も整形対象のため、`docs/` や `.agents/` のファイルまで書き換わる。整形とそのチェックは `src` / `test` に限る (`format` / `verify` スクリプトはそうなっている)
- `package.json` のスクリプトに `check` / `fmt` という名前を付けない。`bun check` を実行すると組み込みの型チェックではなく同名のスクリプトが動く (2026-10-23 に手元で確認)
- 本計画のコードは `bun fmt` で整形済みの形で載せている

- [ ] **Step 9: 実装する (`src/args.ts`)**

`--port` を明示したときは `strictPort: true` にする。`tailscale serve 4400` のような外部のプロキシが指すポートから黙って移らないようにするため。

```ts
import { parseArgs } from "node:util";

export const DEFAULT_HOST = "127.0.0.1";
export const DEFAULT_PORT = 4400;

export const USAGE = `Usage: akapen [dir] [options]

Options:
  -p, --port <number>    Port to listen on (default: 4400, or the next free port)
  -H, --host <address>   Address to bind (default: 127.0.0.1)
  -v, --version          Print the version
  -h, --help             Print this help`;

export type Command =
  | {
      kind: "serve";
      dir: string;
      host: string;
      port: number;
      strictPort: boolean;
    }
  | { kind: "version" }
  | { kind: "help" };

export class UsageError extends Error {}

export function parseCliArgs(argv: string[]): Command {
  let parsed;
  try {
    parsed = parseArgs({
      args: argv,
      options: {
        port: { type: "string", short: "p" },
        host: { type: "string", short: "H" },
        version: { type: "boolean", short: "v" },
        help: { type: "boolean", short: "h" },
      },
      allowPositionals: true,
    });
  } catch (error) {
    throw new UsageError((error as Error).message);
  }
  const { values, positionals } = parsed;

  if (values.help) return { kind: "help" };
  if (values.version) return { kind: "version" };
  if (positionals.length > 1) {
    throw new UsageError(
      `Expected at most one directory, got: ${positionals.join(" ")}`,
    );
  }
  return {
    kind: "serve",
    dir: positionals[0] ?? ".",
    host: values.host ?? DEFAULT_HOST,
    port: values.port === undefined ? DEFAULT_PORT : parsePort(values.port),
    // A port given explicitly must not silently move (e.g. `tailscale serve 4400` proxies to it).
    strictPort: values.port !== undefined,
  };
}

function parsePort(value: string): number {
  const port = Number(value);
  if (!Number.isInteger(port) || port < 0 || port > 65535) {
    throw new UsageError(`Invalid port: ${value}`);
  }
  return port;
}
```

```ts
import { realpathSync, statSync } from "node:fs";
import { resolve } from "node:path";
import { UsageError } from "./args";

export function resolveRoot(dir: string, cwd: string = process.cwd()): string {
  const path = resolve(cwd, dir);
  const stat = statSync(path, { throwIfNoEntry: false });
  if (!stat) throw new UsageError(`Directory not found: ${dir}`);
  if (!stat.isDirectory()) throw new UsageError(`Not a directory: ${dir}`);
  return realpathSync(path);
}
```

- [ ] **Step 4: サーバーを実装する (`src/server.ts`)**

`bun build --compile` は `--production` を含み、`NODE_ENV=production` が埋め込まれる。そのため `bun src/cli.ts` で動かすときだけ開発モード (HMR) になる。

```ts
import index from "./web/index.html";
import type { Health } from "./shared/api";
import { VERSION } from "./version";

export type ServerOptions = {
  root: string;
  host: string;
  port: number;
  strictPort: boolean;
};

const PORT_ATTEMPTS = 20;

export function startServer(options: ServerOptions): Bun.Server<undefined> {
  const attempts = options.strictPort ? 1 : PORT_ATTEMPTS;
  for (let i = 0; ; i++) {
    try {
      return listen(options, options.port + i);
    } catch (error) {
      if (
        i + 1 >= attempts ||
        (error as { code?: string }).code !== "EADDRINUSE"
      )
        throw error;
    }
  }
}

function listen(options: ServerOptions, port: number): Bun.Server<undefined> {
  const health: Health = {
    name: "akapen",
    version: VERSION,
    root: options.root,
  };
  return Bun.serve({
    hostname: options.host,
    port,
    // `bun build --compile` implies --production, which inlines NODE_ENV=production.
    development: process.env.NODE_ENV !== "production",
    routes: {
      "/": index,
      "/api/health": () => Response.json(health),
    },
    fetch: () => new Response("Not Found", { status: 404 }),
  });
}
```

- [ ] **Step 4: 実装する (`src/cli.ts`)**

```ts
import { parseCliArgs, UsageError, USAGE } from "./args";
import { resolveRoot } from "./root";
import { startServer } from "./server";
import { VERSION } from "./version";

function run(argv: string[]): void {
  const command = parseCliArgs(argv);
  switch (command.kind) {
    case "help":
      console.log(USAGE);
      return;
    case "version":
      console.log(VERSION);
      return;
    case "serve": {
      const root = resolveRoot(command.dir);
      const server = startServer({ ...command, root });
      console.log(`akapen ${VERSION} is reviewing ${root}`);
      console.log(`  ${server.url}`);
      return;
    }
  }
}

try {
  run(Bun.argv.slice(2));
} catch (error) {
  if (error instanceof UsageError) {
    console.error(`akapen: ${error.message}\n\n${USAGE}`);
    process.exitCode = 2;
  } else if ((error as { code?: string }).code === "EADDRINUSE") {
    console.error(`akapen: ${(error as Error).message}`);
    process.exitCode = 1;
  } else {
    throw error;
  }
}
```

## リスク

| # | リスク | 対応 |
|---|--------|------|
| R1 | Linux では未確認 | M7 の CI (macOS / Linux) で `bun run verify` を回す。それまでに Linux 機で確認できれば行う |
| R2 | ビルドのスモークテストはバイナリを作るため、`bun test` 全体が数秒長くなる | 手元では全 19 件で約 2 秒。遅くなったら `test/` を別のスクリプトに分ける |
| R3 | ESM のまま `--bytecode` を付けると CommonJS で出力される (`--format` 省略時の既定) | M0 のコードはトップレベル await を使っておらず、そのままで動く。トップレベル await が必要になったら `--format=esm` を足す |
| R4 | `--sourcemap` を付けると `dist/` に `.map` ファイルも出る | `dist/` は `.gitignore` 済み。配布物に含めるのはバイナリだけ (M7) |
| R5 | `bun fmt` を引数なしで実行すると、`docs/` や `.agents/` の Markdown まで整形される (2026-10-23 時点で 23 ファイルが対象になる) | `format` / `verify` スクリプトで対象を `src` / `test` に限る。ドキュメントを `bun fmt` で揃えるかは別途決める |

## 出典
