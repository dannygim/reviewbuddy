# v0.5 レイアウト 詳細計画

**目的: File Tree を隠せるようにし、スレッドを対象の行 / ブロックの直下ではなく右の Comment Pane に並べて (Comment Pane も開閉できる)、v0.5.0 として出す。**

- 設計: [画面構成.md](../design/画面構成.md) (レイアウト / File Tree / Comment Pane) / [要件.md](../design/要件.md) (F4)
- 作成日: 2026-10-30
- 書き方: v0.4 と同じく、コードの全文は載せない (計画を書いてすぐ同じセッションで実装するため)。各タスクはファイル・関数の形・テストケース・確認方法までを定める

## 目的

- File Tree を隠して、Viewer を広く使えるようにする (F4)
- スレッドを本文の行の間に差し込まず、右の列に対象と同じ高さで並べる。本文の流れを切らずに、読みながら横でコメントを読み書きできるようにする (F9 / F10)
- Comment Pane も閉じられるようにし、閉じている間もどこにスレッドがあるかは分かるようにする

## スコープ

- File Tree の開閉のボタン (ヘッダーの左端) と、開閉の状態の保存 (`localStorage` の `reviewbuddy.fileTree`)
- Comment Pane: Source 表示と Preview 表示のスレッド・入力欄を、対象の先頭と同じ高さに右の列で出す。重なりは下へずらす
- Comment Pane の開閉のボタン (Viewer のヘッダーの右端)、閉じたときのアイコンの列、開閉の状態の保存 (`reviewbuddy.commentPane`)
- 対象の直下に差し込む今の仕組み (Source 表示の `tr.code-inline`、Preview 表示の `.preview-slot` と portal) の撤去
- Preview 表示で、複数のブロックにまたがるスレッドを揃えるブロックを、範囲の最後から先頭の側に変える (`blockForRange`)
- README (利用者向け) の追記、v0.5.0 のリリース

## 非スコープ

- 画面の幅に応じて File Tree や Comment Pane を自動で閉じること — ボタンで閉じられる。狭い画面への対応は、使ってみて必要なら追加する
- Comment Pane の幅をドラッグで変えること — 360px で固定する
- カードにホバーしたときに対象の行をハイライトする連動 — カードの見出し (`Line 3`) で対象が分かる。ずれが気になれば追加する (R1)
- 閉じた Comment Pane のときに、今のようにスレッドを直下に出す切り替え — 閉じたときはアイコンだけにする (設計で決めた)
- キーボードショートカットでの開閉
- 開閉の状態をサーバーに保存して参加者間で共有すること — ブラウザごとの設定とする

## 全体の制約

- 依存を増やさない (ADR-0001)。位置の計算は `getBoundingClientRect()` と `ResizeObserver` だけで行う。`ResizeObserver` が `Bun.WebView` の WebKit / Chrome の両方で要素の高さの変化を通知することは、手元で確かめた (出典)
- UI の文言は英語 (`File tree`、`Comments`)
- 開閉の状態はブラウザの `localStorage` だけに保存する。対象ディレクトリには書き込まない
- コードは周りに合わせる (`useSyncExternalStore` のストアの書き方は `src/web/displayMode.ts`、アイコンは `src/web/icons.tsx` の `Icon`)。整形は `bun run format`
- 位置を変えるたびに React の再描画を起こさない。計算した `top` は要素の `style` に直接書く (他の参加者のコメントや入力のたびに全カードを描き直さないため)

  - カードの切り替えを 0.3 秒のアニメーション (`top` の `transition`) にした。15 行目をクリックすると、15 行目のカードは約 300ms で 1340px から 367px へ動く。クリックしたカードへのスクロールは、カードが動き終わってから行う (動き始めにスクロールすると、カードが動いた先の画面の外に出る)
