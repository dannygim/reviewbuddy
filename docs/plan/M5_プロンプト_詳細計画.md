# M5 プロンプト 詳細計画

**目的: 選んだスレッドを Coding Agent 向けのプロンプトに整形してコピーできるようにし、同じ内容を `akapen export` でも出せるようにする。**

- 上位計画: [akapen_実装計画.md](./akapen_実装計画.md) の M5
- 設計: [プロンプト出力仕様.md](../design/プロンプト出力仕様.md) / [API.md](../design/API.md) / [画面構成.md](../design/画面構成.md) / [CLI_仕様.md](../design/CLI_仕様.md)
- 作成日: 2026-10-23
- 書き方: M1 と同じく、コードの全文は載せない

***

## 目的

- 対象の要件: F12 (プロンプトの生成とコピー、`akapen export`) / A3 (送信済みの区別)

## スコープ

- 整形の純粋関数 (`formatPrompt`) と JSONL の出力 (`formatJsonl`)
- `POST /api/prompt` (`exported_at` の記録と、指定があれば Resolve)
- Review パネル (Open / Resolved / Sent のフィルタ、選択、コピー、"Resolve copied threads")
- コピーのフォールバック (Clipboard API → `execCommand('copy')` → 全文を選択済みのモーダル)
- `akapen export [dir] [--session <id>] [--status open|resolved|all] [--format prompt|jsonl]`

## 非スコープ

- `prompt.preamble` / `prompt.max_anchor_lines` / `prompt.resolve_on_copy` を `config.toml` から読むこと → M6 (M5 では既定値 `""` / `30` / `false` を使い、値を差し込める形にだけしておく)

## 完了条件

- [ ] `bun run verify` が通り、CI (macOS / Linux) も通る
- [ ] 設計書の出力例をそのまま期待値にしたゴールデンテストが通る。複数行のコメント・空行・省略・outdated・前置きも単体テストがある
- [ ] UI でコピーすると `exported_at` が記録され、Sent のバッジが付く。"Resolve copied threads" で Resolve される
- [ ] Clipboard API も `execCommand` も使えない場合に、全文を選択済みのモーダルが出る (E2E)
- [ ] `akapen export` の出力が UI でコピーした内容と同じ形式になる。`--format jsonl` の各行が JSON として読める

## タスク分解

### Task 1: 整形

- **Files**: `src/prompt/format.ts` / `src/prompt/format.test.ts`
- **Produces**: `formatPrompt(threads: Thread[], options: { preamble: string; maxAnchorLines: number }): string`、`formatJsonl(threads: Thread[]): string`、`sortThreads(threads)` (ツリー順 → 開始行 → 作成日時)
- **テストケース**: 設計書の出力例 (3 スレッド・リプライ・範囲) / 複数行のコメント / 空行を含む選択行 / `maxAnchorLines` ちょうど・超え (既定 30 で先頭 15 行 + 省略 + 末尾 14 行) / ` (outdated)` / 前置きあり・なし / 0 件のとき / JSONL のキー

### Task 2: API

- **Files**: `src/review/store.ts` (`markExported(ids)`) / `src/review/routes.ts` / `src/shared/api.ts` とテスト
- **Produces**: `POST /api/prompt` — 本文 `{ threadIds: string[]; resolve: boolean; author: string }`、応答 `{ text: string; threads: Thread[] }` (更新後のスレッド)。変わったスレッドは `thread.updated` で配信する。存在しない ID は `404`
- **テストケース**: 出力と `exported_at` / `resolve: true` で Resolve される / 存在しない ID / 空の配列は `400`

### Task 3: Review パネルとコピー

- **Files**: `src/web/ReviewPanel.tsx` / `src/web/clipboard.ts` / `src/web/App.tsx` / `src/web/styles.css` / `test/e2e/prompt.test.ts`
- ヘッダーの "Review (未解決の数)" で右側にパネルを開く。フィルタ、スレッドごとのチェックボックス (開いたときは未解決すべてを選ぶ)、スレッドのクリックで該当のファイルへ移動、"Copy prompt" と "Resolve copied threads"
- コピーは `copyText(text): Promise<"clipboard" | "execCommand" | "manual">`。`manual` のときは全文を選択した textarea のモーダルを出す
- **E2E**: コメント → Review → Copy で Sent が付く / Clipboard API と `execCommand` を使えなくするとモーダルに全文が出る / "Resolve copied threads" で Resolve される

### Task 4: `akapen export`

- **Files**: `src/args.ts` / `src/cli.ts` / `src/prompt/export.ts` / `test/cli.test.ts`
- `export` をサブコマンドとして解析する (同名のディレクトリは `./export` で開く)。対象は `--session` の ID か、ルートの active なセッション (無ければエラー)。`exported_at` は記録しない
- **テストケース**: prompt 形式 / `--status resolved` / `--format jsonl` / active なセッションが無いとき (終了コード 1)
