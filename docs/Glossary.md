| **用語**                       | **意味**                                                                            | **備考**                                                                               |
| ---------------------------- | --------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| reviewbuddy | 対象ディレクトリのファイルを複数人がブラウザで閲覧し、行・ブロックにコメントして Coding Agent 向けのプロンプトにする CLI / Web アプリ | 名前は review + buddy (一緒にレビューする相棒)。v0.2.0 までの名前は akapen ([ADR-0008](./adr/0008-rename-to-reviewbuddy.md)) |
| ルート | reviewbuddy がレビューの対象にするディレクトリ。`reviewbuddy [dir]` の `dir` (省略時はカレントディレクトリ) の realpath | 中のファイルは読み取り専用で扱う |
| セッション | ルートごとのレビューの単位。`~/.config/reviewbuddy/sessions/<id>/` に保存する。状態は active / ended | 同じルートで再起動すると active なセッションを再開する |
| スレッド | ファイルの行範囲にひも付く、元コメントとリプライのまとまり。状態は open / resolved | 1 件目のコメントが元コメント |
| アンカー | スレッドがひも付く行範囲と、作成時点のその行の内容 (`anchor_text`) | プロンプトにはアンカーの内容を載せる |
| Outdated | ファイルの変更でアンカーの行が見つからなくなったスレッドの状態 | GitHub の Pull Request と同じ考え方 |
| Sent | プロンプトとしてコピー済み (`exported_at` あり) のスレッドに付く表示 | |
| プロンプト | 選んだスレッドを Coding Agent に渡すために決まった形式で整形したテキスト | UI からのコピーと `reviewbuddy export` で出力する |
| Coding Agent | Claude Code など、指示を受けてコードやドキュメントを修正する AI Agent | |
| Nickname | 参加者が初回アクセス時に入力する表示名 | 自己申告で、本人の確認はしない |
| PIN | reviewbuddy を起動するたびにターミナルに表示される 6 桁の数字。参加者は最初の画面で Nickname と一緒に入力する | 起動ごとに変わる。[ADR-0007](./adr/0007-access-pin.md) |
| Preview 表示 / Source 表示 | Markdown をレンダリングした表示 / 元のテキストを行番号付きで出す表示 | どちらで作ったスレッドも同じ行範囲で保存される |
| FileIndex | ルートの中で File Tree に出すファイルの一覧。`git ls-files` (Git 管理外は `.gitignore` の判定) から作る | [ファイル一覧と表示.md](./design/ファイル一覧と表示.md) |
| ツリー順 | 同じ階層ではディレクトリを先にし、名前で並べる順序。File Tree とプロンプトの並び順に使う | 大文字・小文字を区別せずに比べ、同じなら区別して比べる |
| 再アンカー | ファイルが変わったときに、スレッドのアンカーの内容を探し直して行範囲を更新すること | 見つからなければ Outdated |
| Review パネル | 全ファイルのスレッドの一覧から対象を選び、プロンプトを生成・コピーする画面 | |
| プレゼンス | 接続中の参加者と、各参加者が開いているファイルの表示 | |
| Display mode | 画面の配色の選び方。Light / Dark / System (OS のライト / ダーク設定に従う) の 3 つ | ヘッダーで切り替え、ブラウザごとに `localStorage` に保存する。既定は System。[画面構成.md](./design/画面構成.md) |
| read-only | 終了 (ended) したセッションの状態。閲覧はできるが、コメントの書き込みはできない | `reviewbuddy session reopen` で戻せる |
| tailnet | Tailscale でつながった端末のネットワーク | 共有には `tailscale serve` (HTTPS) を推奨 |
