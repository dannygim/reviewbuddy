# プロンプト出力仕様

**目的: スレッドを Coding Agent に渡すプロンプトの形式、コピーの動作、`akapen export` の出力形式 (prompt / JSONL) を定める。**

- 対象の要件: F12 / A3 ([要件.md](./要件.md))
- 対応する調査: [ブラウザ制約_Tailscale_調査.md](../research/ブラウザ制約_Tailscale_調査.md) (コピーのフォールバックの理由)

***

## 形式

```text
{連番}. {ファイルパス}:{開始行}[-{終了行}]
  {選択行の内容 (各行を 2 スペースでインデント)}

  {元コメント} by {Nickname}
  {リプライ 1} by {Nickname}
  {リプライ 2} by {Nickname}

{次のスレッド}
```

- 並び順はファイルパスのツリー順 ([ファイル一覧と表示.md](./ファイル一覧と表示.md)) → 開始行 → 作成日時
- 連番は 1 から振る
- 単一行は `path:3`、範囲は `path:8-10`
- 選択行の内容は `anchor_text` (作成時点の元ファイルの行) を使う。空行はインデントせずに空行のまま出す
- コメントの本文が複数行の場合は各行を 2 スペースでインデントし、` by {Nickname}` は最終行の末尾に付ける
- 選択行が `prompt.max_anchor_lines` (既定 30) を超える場合は、先頭 `ceil((max - 1) / 2)` 行と末尾 `floor((max - 1) / 2)` 行を残し、間に `… (N lines omitted)` の 1 行を入れる (出力は合わせて `max` 行になる。既定なら先頭 15 行 + 省略の 1 行 + 末尾 14 行)
- Outdated のスレッドは、見出しの行の末尾に ` (outdated)` を付ける
- `prompt.preamble` が空でなければ、先頭に置いて空行を 1 つ挟む (既定は空)
- スレッドの間は空行 1 つで区切り、出力の末尾は改行 1 つで終える

## 出力例

```text
1. doc/A.md:3
  ## インストール手順

  Bun の必要バージョンを明記してほしい by Alice
  1.4 以上で良いと思う。Rust 版以降の API を使うので by Bob
  了解、1.4 以上で by Alice

2. doc/B.md:8-10
  - 保存先は `~/.config` 配下
  - ログは標準出力のみ
  - 設定ファイルは TOML

  保存先は XDG_CONFIG_HOME を優先するようにしてほしい by Bob

3. mise.toml:8
  bun = "1.3.8"

  1.4.4 に上げて by Bob
```

## UI でのコピー

- Review パネルで対象のスレッドを選ぶ (既定: 未解決すべて)。生成はサーバーの `POST /api/prompt` で行い、`akapen export` と同じ関数を使う ([API.md](./API.md))
- コピーは次の順に試す
  1. `navigator.clipboard.writeText()` (安全なコンテキストのとき)
  2. 非表示の textarea + `document.execCommand('copy')` (`http://100.x.y.z:4400` などの安全でないコンテキスト)
  3. 全文を選択済みの textarea をモーダルで出す (手動でコピーしてもらう)
- コピーしたスレッドに `exported_at` を記録し、「Sent」のバッジを出す
- "Resolve copied threads" のチェックボックス (既定は `prompt.resolve_on_copy`、その既定は `false`) が付いていれば、まとめて Resolve する

## `akapen export`

```sh
akapen export [dir] [--session <id>] [--status open|resolved|all] [--format prompt|jsonl]
```

- 既定はルートの active なセッションの、未解決のスレッドを prompt 形式で標準出力に出す (`| pbcopy` や Agent への直接のパイプ用)
- サーバーが起動していても読める (SQLite の WAL + `busy_timeout`)。`exported_at` は記録しない (UI のコピーだけが記録する)
- `--format jsonl` は 1 行に 1 スレッドの JSON を出す。キーは次のとおり

```json
{"id":"01JB...","path":"doc/A.md","startLine":3,"endLine":3,"status":"open","outdated":false,"anchorText":"## インストール手順","originView":"preview","createdBy":"Alice","createdAt":"2026-10-23T06:30:12.345Z","resolvedBy":null,"resolvedAt":null,"exportedAt":null,"comments":[{"id":"01JB...","author":"Alice","body":"Bun の必要バージョンを明記してほしい","createdAt":"2026-10-23T06:30:12.345Z","updatedAt":null}]}
```

## テスト観点

- 上の出力例をそのまま期待値にしたゴールデンテスト (単一行・範囲・リプライ)
- 複数行のコメント、空行を含む選択行、`max_anchor_lines` ちょうど / 超え、` (outdated)`、`preamble` あり / なし
- 並び順: ツリー順 → 開始行 → 作成日時
- JSONL の各行が JSON として読めて、キーがそろっている
- UI のコピーと `akapen export` の出力が一致する
