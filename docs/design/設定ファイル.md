# 設定ファイル

**目的: 任意で置ける `config.toml` の場所・優先順位・検証の規則・キーの一覧を定める。**

- 対応する調査: [Bun_調査.md](../research/Bun_調査.md) (`Bun.TOML`)

***

## 要否

**必須にはしない (無くても既定値で動く) が、用意する。** 理由:

- Tailscale 経由で毎回使うなら `host` を固定したい (毎回 `--host` を打たない)
- プロンプトの前置きの文や省略の閾値は、使う Agent や好みによって変えたい
- セッションの保持期間は、人によって適切な値が違う
- `.gitignore` には書かないが画面では隠したいもの (ロックファイルなど) がある

***

## 仕様

- 場所: `<akapen のホーム>/config.toml` (既定 `~/.config/akapen/config.toml`。[保存先とセッション.md](./保存先とセッション.md))。形式は TOML で、`Bun.TOML.parse` で読む
- 優先順位: CLI のフラグ > 環境変数 (`AKAPEN_PORT` / `AKAPEN_HOST`) > `config.toml` > 組み込みの既定値
- 未知のキーは警告を出して無視する。型や範囲が違う値は、キーのパス付きのエラー (例: `akapen: config.toml: server.port must be an integer between 0 and 65535`) で起動を止める (終了コード 1)
- `akapen config init` でコメント付きの雛形を作る (既存のファイルは上書きしない)。雛形はテキストとして持つ (`Bun.TOML.stringify` はコメントを残さないため)
- `akapen config show` で、反映後の値を TOML で出す
- ルートに置くプロジェクト単位の設定 (`.akapen.toml`) は v1 では作らない (v2 候補)

***

## キー一覧

```toml
# ~/.config/akapen/config.toml

[server]
host = "127.0.0.1"          # tailnet の他の端末から直接つなぐなら "0.0.0.0"
port = 4400                 # ここに書くと明示扱い (使用中でも別のポートに移らない)
open_browser = false        # 起動時にブラウザを開く
allowed_hosts = []          # Host ヘッダーとして許す名前 (IP / localhost / *.ts.net 以外。例: MagicDNS の短い名前)

[viewer]
max_highlight_bytes = 2000000           # これを超えたらハイライトなしで表示する
exclude = []                            # .gitignore に加えて画面から隠すパターン (gitignore の書式)。例: ["*.lock", "pnpm-lock.yaml"]

[prompt]
preamble = ""               # プロンプトの先頭に付ける文 (空なら付けない)
max_anchor_lines = 30       # 選択行がこれを超えたら中間を省略する (3 以上)
resolve_on_copy = false     # コピーしたスレッドを自動で Resolve する

[retention]
idle_days = 60              # 無操作の active なセッションを自動で終了するまでの日数 (0 = しない)
ended_days = 14             # 終了したセッションを自動で削除するまでの日数 (0 = しない)
```

| キー | 型 | 既定値 | 制約 |
|------|----|--------|------|
| `server.host` | 文字列 | `"127.0.0.1"` | 空でない |
| `server.port` | 整数 | `4400` | 0〜65535 |
| `server.open_browser` | 真偽値 | `false` | |
| `server.allowed_hosts` | 文字列の配列 | `[]` | |
| `viewer.max_highlight_bytes` | 整数 | `2000000` | 1 以上 |
| `viewer.exclude` | 文字列の配列 | `[]` | gitignore の書式 |
| `prompt.preamble` | 文字列 | `""` | |
| `prompt.max_anchor_lines` | 整数 | `30` | 3 以上 |
| `prompt.resolve_on_copy` | 真偽値 | `false` | |
| `retention.idle_days` | 整数 | `60` | 0 以上 |
| `retention.ended_days` | 整数 | `14` | 0 以上 |

`viewer.exclude` の例 (`*.lock` など) は雛形のコメントで示すだけで、既定値は空にする (ロックファイルをレビューしたい場合もあるため)。

***

## テスト観点

- ファイルが無いときは既定値になる
- 優先順位: フラグ > 環境変数 > ファイル > 既定値
- 未知のキーで警告が出て、起動は続く
- 型・範囲の違いで、キーのパス付きのエラーになる
- `config init` が既存のファイルを上書きしない。作った雛形が `Bun.TOML.parse` で読めて、既定値と一致する
